## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly:

1. **Do not** open a public GitHub issue describing the vulnerability.
2. Email **methilashiv@gmail.com** with details, reproduction steps, and impact assessment.
3. You will receive an acknowledgment within 72 hours and a fix timeline within 7 days.

Please allow reasonable time for a fix before any public disclosure.
